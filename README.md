# Traffic Volume Prediction

## Introduction

This project predicts hourly traffic volume using machine learning and deep learning models.

## Objectives

* Analyze traffic patterns
* Build ML and DL models
* Compare forecasting performance

## Dataset

Metro Interstate Traffic Volume Dataset from Kaggle.

## Models

* Linear Regression
* Random Forest
* XGBoost
* LSTM
* GRU

## Project Structure

* data/: dataset files
* notebooks/: Jupyter notebooks
* src/: source code
* reports/: proposal and reports
